# Alura Play
Projeto desenvolvido com o aprendizado de 3 cursos sobre php e suas boas práticas!<br>
Os cursos dos quais o projeto foi desenvolvido:
- PHP na web: conhecendo o padrão MVC
- PHP na web: lidando com segurança e API
- PHP na web: aplicando boas práticas e PSRs<br><br>

O projeto tem foco na exibição de vídeos com recursos de adicionar, editar e excluir videos aplicando boas práticas e o padrão MVC. Também com foco na criação de usuários para ter o acesso a estes recursos, usando oque foi passado no curso de segurança e API. 

Para executar o projeto:<br>
- Com o php instalado na máquina, execute: php -S localhost:8080 -t public/
- Composer install para dependências
- Crie um usuário com o comando php criar-usuario.php "email@exemplo.com" "teste123" na pasta raíz do projeto
